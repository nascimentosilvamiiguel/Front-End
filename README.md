## Como visualizar

Abra o arquivo `index.html` na raiz do repositório (ou publique via GitHub Pages) para acessar o menu com todos os exercícios. Cada exercício está em sua própria pasta (`exercicio-01`, `exercicio-02`, ...) contendo `index.html`, `estilo.css` e `script.js`, e cada um possui um link para voltar à página inicial.
